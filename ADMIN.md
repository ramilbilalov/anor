# Инструкция по админ-панели «Анор»

Админ-панель — это закрытая часть сайта для управления меню, заказами и
информацией о ресторане. Обычный посетитель сайта туда не попадёт.

## 1. Как войти

1. Откройте адрес сайта и добавьте в конце `/admin`
   (например: `https://ваш-домен.ru/admin`).
   Внизу главной страницы также есть ссылка **«Панель администратора»**.
2. Введите **логин** и **пароль**.
   - По умолчанию логин `admin`, пароль `admin123`.
   - Реальные логин и пароль задаются в файле `.env`
     (`ADMIN_USERNAME` и `ADMIN_PASSWORD`) — см. раздел «Безопасность».
3. После входа вы попадёте в раздел **«Заказы»**.

Вы остаётесь авторизованы 7 дней, пока не нажмёте **«Выйти»** в правом верхнем
углу.

### Защита от подбора пароля
После **5 неверных** попыток входа вход с этого устройства/сети блокируется на
**15 минут** — так пароль нельзя подобрать перебором. Если случайно
заблокировали себя, подождите 15 минут или перезапустите сервер.

## 2. Раздел «Заказы»

Здесь появляются все заказы, оформленные покупателями. Каждый заказ содержит:

- **Номер** и дату/время;
- **Имя** и **телефон** клиента (по телефону можно позвонить прямо из карточки);
- **Адрес доставки** и **комментарий**;
- **состав заказа** и **итоговую сумму**;
- **статус** заказа.

### Как менять статус заказа
Справа в карточке заказа есть выпадающий список статусов. Выберите нужный —
изменение сохраняется сразу. Доступные статусы:

| Статус | Когда ставить |
| --- | --- |
| Новый | Заказ только что поступил (ставится автоматически) |
| Подтверждён | Вы приняли заказ в работу |
| Готовится | Блюда готовятся на кухне |
| В доставке | Курьер повёз заказ |
| Выполнен | Заказ доставлен |
| Отменён | Заказ отменён |

Новые заказы отображаются сверху. Обновите страницу, чтобы увидеть свежие
заказы.

## 3. Раздел «Меню»

Здесь вы управляете категориями и блюдами. Всё, что вы меняете, сразу видно
покупателям на сайте.

### Категории
- **Добавить категорию**: введите название в поле сверху и нажмите
  **«Добавить категорию»** (например: «Салаты», «Десерты»).
- **Удалить категорию**: кнопка **«Удалить категорию»** справа от названия.
  ⚠️ Вместе с категорией удаляются все блюда в ней.

### Блюда
Внутри каждой категории — список блюд. Для каждого блюда доступно:

- **+ Блюдо** (справа от названия категории) — добавить новое блюдо в эту
  категорию.
- **Изменить** — открыть карточку блюда для редактирования.
- **Удалить** — удалить блюдо.
- **В наличии / Скрыто** — нажатие на этот значок скрывает или показывает блюдо
  на сайте (удобно, если блюдо временно закончилось, но удалять его не нужно).

### Карточка блюда (создание/редактирование)
При нажатии **«+ Блюдо»** или **«Изменить»** открывается окно с полями:

- **Название** *(обязательно)* — название блюда.
- **Категория** *(обязательно)* — в каком разделе показывать.
- **Цена (₽)** *(обязательно)* — цена в рублях, целым числом (например `450`).
- **Описание** — короткий текст (показывается в каталоге и на странице блюда).
- **Состав** — из чего блюдо (показывается на странице блюда).
- **Фотография** — нажмите **«Выберите файл»**, выберите картинку
  (JPG, PNG, WEBP или GIF, до 5 МБ). После загрузки появится превью.
  Кнопка **«Удалить фото»** убирает картинку.
- **Показывать в меню (в наличии)** — галочка, показывать ли блюдо покупателям.

Нажмите **«Сохранить»**. Изменения сразу появятся на сайте.

## 4. Раздел «Настройки»

Здесь редактируется информация о ресторане, которая показывается на сайте
(в шапке главной, в подвале и на странице «О ресторане»):

- **Название ресторана** *(обязательно)*;
- **Описание** — короткий текст о кухне;
- **Адрес**;
- **Телефон** — по нему клиент сможет позвонить (кликабельно);
- **Часы работы**;
- **Условия доставки** — зона, стоимость, минимальный заказ.

Заполните нужные поля и нажмите **«Сохранить»**. Пустые поля просто не будут
показываться на сайте.

## 5. Безопасность (важно перед запуском)

1. **Смените логин и пароль.** Откройте файл `.env` и задайте свои значения:
   ```
   ADMIN_USERNAME="ваш_логин"
   ADMIN_PASSWORD="надёжный_пароль"
   ```
   Используйте длинный пароль (12+ символов, буквы разного регистра, цифры,
   символы).

2. **Смените секрет сессии.** В `.env` задайте случайную длинную строку:
   ```
   SESSION_SECRET="длинная-случайная-строка"
   ```
   Сгенерировать можно командой:
   ```bash
   node -e "console.log(require('crypto').randomBytes(32).toString('hex'))"
   ```

3. После изменения `.env` **перезапустите сайт**, чтобы новые значения
   применились.

4. Работайте с админкой только по **HTTPS** (см. `DEPLOY.md`), чтобы пароль не
   передавался в открытом виде.
